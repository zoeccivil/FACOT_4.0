TECHNICAL DETAILS:
─────────────────

Theme Application Order:
  1. Initialize QApplication
  2. Load theme manager
  3. Apply saved theme (or default to "light")
  4. Append safe menu styles (theme-aware)
  5. Show main window

Stylesheet Approach:
  • Theme manager applies base QSS from style_template.qss
  • Menu styles are appended (not overridden)
  • Uses regex to detect existing menu styles
  • Preserves all existing theme manager functionality

Color Palette (Light Theme):
  Background:      #F1F5F9 (app background)
  Surface:         #FFFFFF (cards, tables)
  Surface Alt:     #F8FAFC (alternate rows)
  Foreground:      #0F172A (text)
  Primary:         #2563EB (buttons, highlights)
  Border:          #E2E8F0 (borders, lines)


BUILD PROCESS:
─────────────

1. Creates .venv_build virtual environment
2. Installs all requirements from requirements.txt
3. Detects PyQt6 installation directory
4. Collects WebEngine binaries and resources
5. Packages all data directories
6. Builds single-file executable with PyInstaller
7. Output: dist/facot.exe (~150-250 MB)
